Claude Workstation privacy policy

Effective September 24, 2026.

Who uses it

Claude Workstation is a personal tool used only by its owner. It isn't offered to the public.

What it reads

With the owner's consent, it reads the owner's Google account data through these read-only permissions:

  • Gmail: read messages (gmail.readonly)
  • Google Drive: read files (drive.readonly)
  • Google Calendar: read calendars and events (calendar.readonly)
  • Google Sheets: read spreadsheets (spreadsheets.readonly)
  • Google Docs: read documents (documents.readonly)

It can't send email, and it can't create, change, share, or delete anything.

How the data is used

The data is used only for the owner's own tasks, such as a job search: finding recruiter emails, reading a CV, or checking interview times. When the owner asks the assistant something, the data needed to answer goes to the AI model the owner uses, Anthropic's Claude served through Google Cloud Vertex AI.

Storage

The access token is stored on the owner's workstation disk, readable only by the owner's account. Claude Code keeps session transcripts, which can include data the assistant read, on the same workstation. No server is run for this tool.

Sharing

Data isn't sold, shared with anyone else, used for ads, or used to train AI models. The tool collects no analytics.

Claude Workstation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions. That invalidates the stored token.

Contact

Open an issue at github.com/gctjiang/claude-workstation.
